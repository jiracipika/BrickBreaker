# 🎮 Brick Breaker

A modern implementation of the classic Brick Breaker game built with TypeScript and HTML5 Canvas.

![Brick Breaker Game](https://i.imgur.com/example.png)

## 🎯 Features

- Smooth paddle control with mouse/touch input
- Responsive design that works on both desktop and mobile
- Pause functionality (Space bar)
- Start screen with instructions
- Game over screen with restart option
- Score tracking
- Modern visual design with Tailwind CSS

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/jiracipika/BrickBreaker.git
```

2. Navigate to the project directory:
```bash
cd brick-breaker
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. Open your browser and navigate to `http://localhost:3000`

## 🎮 How to Play

- Move your mouse or finger to control the paddle
- Prevent the ball from falling below the paddle
- Break all the bricks to win
- Press SPACE to pause/unpause the game
- Try to achieve the highest score!
